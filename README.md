# Bird Sort Color

A mobile puzzle game developed in **Unity with C#**, inspired by the *Bird Sort* genre. The goal of the game is to rearrange colored birds so that birds of the same color are placed together on the same branch.

The project was developed as a **group software engineering project**, with a focus not only on game development but also on collaborative development, iterative delivery, testing, and the application of the **Agile methodology (Scrum)**.

## 🎮 Game

In each level, birds of different colors are distributed across several branches. The player has to move them between branches and organize them so that all birds of the same color end up together.

The game includes:

* **Color-based sorting puzzle mechanics**
* **Randomly generated levels**, allowing virtually unlimited gameplay
* **Help and assistance mechanics** to support the player when needed
* **Mobile-oriented gameplay and interface**
* **Online progress sharing**, allowing players to share their game progress

## 🧪 Testing

Testing was an integral part of the development process. The team implemented and executed tests to verify the correct behavior of the main game functionalities and identify potential issues during development.

## 👥 Development Process

The project was developed collaboratively by a team following an **Agile development process based on Scrum**.

Development was organized into iterative cycles, with tasks divided among team members and progressively integrated into the project. Regular coordination and incremental development allowed the team to continuously evaluate the state of the project and adapt the implementation to emerging requirements.
